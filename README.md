> *A God-Mode Autonomous AI Software Engineer for Android.*

This is not an app. It's a **platform**. 163 Kotlin files. 60,000+ lines. Built from the ground up to let AI agents write code, run terminals, control the OS, manage files, and self-heal build failures — autonomously, on your phone.

```
📊 By the Numbers:
   ├── 165 Kotlin files          (Kotlin 2.0 + Jetpack Compose)
   ├── 60,000+ lines of code
   ├── 70 integrated tools
   ├── 12 Android services
   └── 5 AIDL interfaces
```

**Core Architecture:**
- **ReAct Loop Engine** (`AgentPipeline.kt`) — Reason → Act → Observe, up to 50 iterations
- **Multi-Agent Swarm** (`SwarmOrchestrator.kt`) — parallel workers on complex tasks
- **On-device LLM** via `llama.cpp` JNI (i2_s quantization, zero cloud dependency)
- **Dual GitHub AI** — GitHub Copilot (zero-registration) + GitHub Models
- **RAG System** — Room DB vector search + TF-IDF semantic memory
- **Always-On Voice** — STT/TTS with Arabic/English wake-word detection
- **OS-Level Execution** — Shizuku (ADB-level, no full root needed)
- **Agent Brain** — ToolExecutionJournal + Q-Learning tool scorer

**Tool Categories (70 tools):**
File & System · Git & GitHub · Memory & RAG · Web & Network · Telegram · Discord · WhatsApp · UI Automation · Logcat Analysis · Task Scheduling · Voice Commands · Security Analysis · Predictive Analytics · Headless Browser · Social Media

Stack: Kotlin 2.0 · Jetpack Compose · Hilt · Room · Retrofit · llama.cpp (JNI) · Shizuku · AIDL
